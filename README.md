# Wallet-Score-Analysis

## Privacy Policy

**[Read the Copytrade Wallet Score privacy policy](https://walletanalysisdev.github.io/Wallet-Score-Analysis/)**

Copytrade Wallet Score is a Chrome extension that scores Solana wallets for copy trading. It runs entirely in your browser: there is no account, no server and no tracking. Your Helius API key and everything you analyze stay on your device and are only sent to the data services the extension uses (Helius, GeckoTerminal and Binance.US).
